# Generative AI Projects and Assignments

A learning repository for exploring practical concepts in **Generative
AI, text embeddings, semantic similarity, vector databases, and
Retrieval-Augmented Generation (RAG)**. It brings together hands-on
learning notebooks and assessment documents in one place.

**Repository:**
[GEN-AI-PROJECT-AND-ASSIGNMENT](https://github.com/Manideep-hub/GEN-AI-PROJECT-AND-ASSIGNMENT)

## Contents

### 1. Embeddings and Semantic Similarity

-   **`Word_Embeddings_MD.ipynb.txt`** --- learning material on word
    embeddings and representing text numerically.
-   **`HuggingFace_Embedding_Scratch_to_Intermediate_MD.ipynb.txt`** ---
    embedding concepts and a progression from foundational
    implementation toward using Hugging Face embedding tools.
-   **`Calculating_Cosine_Similarity_Mathematically_MD.ipynb.txt`** ---
    mathematical explanation and practice for calculating cosine
    similarity between vectors.

## Getting Started

### Requirements

The exact dependencies depend on the notebook or exercise you want to
run. Common tools for this type of work include:

-   Python 3
-   Jupyter Notebook or Google Colab
-   Relevant packages such as `numpy`, `sentence-transformers` or
    Hugging Face libraries, and `chromadb` when required by a particular
    notebook

Install only the packages required by the notebook you are using. For
example:

``` bash
python -m venv .venv
```

Activate the environment:

**Windows**

``` bash
.venv\Scripts\activate
```

**macOS / Linux**

``` bash
source .venv/bin/activate
```

Install packages as needed, for example:

``` bash
pip install numpy chromadb sentence-transformers
```

Some notebooks may require additional packages or API credentials. Check
the notebook instructions before running cells, and never commit API
keys or other secrets to GitHub.

### Clone the Repository

``` bash
git clone https://github.com/Manideep-hub/GEN-AI-PROJECT-AND-ASSIGNMENT.git
cd GEN-AI-PROJECT-AND-ASSIGNMENT
```

### Open the Learning Materials

1.  Open the repository in VS Code or another editor.
2.  Review the relevant notebook material and its setup instructions.
3.  If a file ends in `.ipynb.txt`, it is currently stored as a
    text-exported notebook file rather than a standard `.ipynb`
    filename. Inspect its contents and convert it to a valid Jupyter
    notebook format before attempting to run it as a notebook.
4.  Run the cells in order and review the outputs.

PDF files can be opened with any standard PDF reader.

## Suggested Learning Path

1.  Start with **Word Embeddings** to understand how text can be
    represented numerically.
2.  Study **Cosine Similarity** to learn how vector similarity can be
    measured.
3.  Explore **Hugging Face Embeddings** to understand practical
    embedding workflows.
4.  Learn the purpose of **Vector Databases** and explore ChromaDB.
5.  Practice ChromaDB CRUD operations.
6.  Study document loading and chunking strategies.
7.  Work through the RAG practice material to connect retrieval
    concepts.

## Learning Goals

By working through the materials, you can build an understanding of how
text is represented as vectors, how similarity can support semantic
retrieval, how vector databases store and manage embeddings, and how
document processing fits into RAG workflows.
